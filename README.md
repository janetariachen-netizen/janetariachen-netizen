# sherlock-for-background-search-of-chinese-suppliers

A Codex Skill package for supplier background search workflows focused on Chinese suppliers and global buyers.

It operationalizes:
- account discovery with Sherlock
- supplier/buyer intent signal extraction
- contact harvesting with confidence filtering
- direct-vs-expanded evidence separation for due diligence
